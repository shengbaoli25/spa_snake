# 双螺旋 SPA 真机工作台

网页提供 M3 / M4 单独测试、全局相机测速、真实数据采集、预测模型预训练和真实轨迹 PPO。算法依据作者确认的论文 2026-10-05 本地版本，范围为两节 SPA 验证。论文稿件不包含在此代码仓库中。

## 启动与连接

双击 `spa_control/start_web.bat`，保持服务运行，然后访问 <http://127.0.0.1:8765/>。也可在项目根目录运行：

```powershell
& .\spa_control\.venv\Scripts\python.exe -m spa_control.web_server --port 8765
```

服务只监听本机，启动不连接设备或运行电机。连接 C 板时先发送 `CTRL STOP`。“设置与运行”和“单机测试”均提供“清除故障”按钮，支持 USB 关闭、命令超时、反馈过期、过流、过温和 CAN 错误锁存。先排除触发原因，再手动点击：后台重新发送 STOP，检查至少 1.2 秒连续静止、低电流、低温和正常 CAN 反馈，随后发送一次 CLEAR 并核验板端确认及新鲜零输出。清除后保持停机，不自动续跑；危险条件仍在时拒绝清除。未知、FATAL、BAD_COMMAND 故障不支持此按钮。过流提示显示触发电机与电流原始值，不代表安培。

## 先辨认 M3 / M4

1. 开启电机电源、将机器人放稳并让手离开旋转件，点击“连接 C 板并停止”。等待两路反馈正常、故障为 `NONE`。
2. 在“M3 / M4 单独测试与反馈”保留默认 **−60 rpm、3 秒**，点击“单独测试 M3”。观察哪一个外筒转动、朝哪个方向；结束后会自动停止。
3. 再点击“单独测试 M4”。每次只给选中的电机非零目标，另外三路为零。需要反向时改转速正负号。
4. 在“真机强化学习”选择驱动前节的电机。两个前进指令方向默认均为负：用户此前已观察到 **M3 / M4 各 −60 rpm** 时两个外筒反向转、中轴基本稳定。按单机观察结果调整。

页面顶端、单机测试区和实验区都提供停止按钮，停止会同时取消实验和电机续租。单机测试不依赖相机；界面允许非零整数转速 ±500 rpm、0.5–5 秒。后端确认静止、切换 `BENCH`、检查 ACK 后才发送运动指令，结束检查停止 ACK 与零输出。浏览器关闭或控制心跳中断也触发停止。

电机反馈是转子相对定子的转速，不能直接当作机器人对地速度。`torque` 为电流原始值，`setV` 为输出控制量，不能解释成标定力矩或实测电压。C 板放在机器人外部时，其 IMU 不能反馈中轴滚转。

## 设置目标速度与距离

用户已确认 **螺旋导程 30 mm/转、传动比 1:1**。网页固定使用这两个参数：

```text
外筒 rpm = 电机 rpm / 传动比
理论前进速度 = 轨道方向 × 外筒 rpm × 30 / 60000  （m/s）
100 rpm → 0.05 m/s；60 rpm → 0.03 m/s
```

理论值假设无滑移、中轴不滚动，两节共同推进速度不相加。实测对地速度来自全局相机。

“目标速度、距离与实测”区域只做预览。真正运行使用“真机强化学习”中保存的设置：标称转速与理论目标速度联动，两个电机的指令正负号单独选择；“前进对应相机轨道方向”决定相机速度和位移的正负。默认目标距离 0.3 m、最长时长 10 秒，运行达到任一条件会请求停止。目标距离是相机检测后的停机触发点，不保证零制动距离。

点击“保存实验设置”不会运行电机。保存位置为 `spa_control/runs/paper_two_motor/settings.json`。改变前后顺序、方向、转速等模型相关设置后，旧预测模型不能直接沿用，需要对应数据重新预训练。

## 相机

**全局相机**固定在外部拍摄运动区域。先连接相机，按轨道已知位置点选至少两个标定点并应用，再拖框选择静止机器人头部。位置递增方向就是速度正方向。算法沿用分段轨道投影、CSRT 头部前沿跟踪、低通和尾窗速度估计；移动相机或改变焦距、分辨率后须重新标定。实验期间跟踪失效、数据过期或标定变化会停止。

**SPA-CAM 头部相机**通过蓝牙经典 SPP 的传出串口连接，在 Windows 中选择 SPA-CAM 对应的传出 COM 端口。Windows“已配对”不代表串口已建立链路。网页收到并校验 JPEG 后显示画面；端口不通或断帧会保留实际错误。头部图像是策略输入，不能代替全局相机速度。

## 从基线到真机强化学习

1. **基线运行**：保存前后顺序与运动参数，连接 C 板并完成全局相机标定、跟踪。点击“基线运行”，两路按标称目标运动并记录区间奖励。这一步不要求 SPA-CAM。
2. **采集预训练数据**：连接 SPA-CAM 并确认图像新鲜，填写数据准备组名，点击“采集预训练数据”。后节在可执行的 −5 / 0 / +5 rpm 候选中均衡采集，前节保持标称转速。命令仍限制在 ±500，边界动作会投影并去重。
3. **采集另一准备组**：在另一组独立场地准备下更改组名，再保存并采集，其他模型相关参数保持一致。组名标记实际独立准备；只改名字不能把同一准备变成独立验证。训练与验证按整组划分，不随机拆分相邻帧。
4. **训练预测模型**：至少两组对应配置的数据，训练集至少 6 个有效区间、验证集至少 2 个有效区间。点击后保持电机停止，依次训练参考预测和历史修正部分，再冻结表征与预测器。页面显示进度及完成状态。
5. **开始真机强化学习**：按钮仅在模型准备好且设备数据有效时可用。每次运行采集当前策略的新轨迹，结束并确认零输出后更新 PPO。再次点击开始下一轮；不会自动连续开动机器人。

运行与训练状态、当前完整奖励、位移、样本数和策略版本在实验区显示。按钮不可用时页面显示缺少的条件。准备阶段、相机断帧、动作确认超时或数据不完整会结束本轮；无效采集不得进入 PPO 更新。

## 论文对齐与完整区间奖励

`web_experiment.py` 连接两路 `two_motor_preview.py`、官方冻结的 MobileNetV3-Small 特征、近期驱动历史、前节因果历史与 null 选择、锚定预测修正和离散残差策略。**全局相机的实测位置/速度只用于奖励、监督标签和评价，不输入 actor。** 策略可见目标速度，但看不到实际全局相机速度。

每个动作区间以新鲜真实电流、测速反馈计算：

```text
e = (区间平均实测速度 − 目标速度) / max(|目标速度|, 0.005)
r = exp(−e² / (2 × 0.5²))
    − 0.2 CI − 0.1 Co − 0.02 Ca − 0.02 Cs − 1.0 f
```

`CI` 是电流相对 7000 原始值阈值、超过 0.7 警戒比例后的平方超额代价；`Co` 是任一电机超过该警戒比例的区间占比；`Ca=(残差/5)²`；`Cs=((本次残差−上次残差)/10)²`；`f` 是保护/提前停止标记，并为失败剩余步加入吸收尾项。区间按 0.1 秒因果网格汇总，持有值不冒充新包；缺少新鲜数据时不补零、不用模型预测代替奖励。

真实执行动作得到的位移、后节峰值电流、超限占比和干预标记用于监督预训练。历史数据只进入监督学习；PPO 只接收本轮当前版本策略的真实随机轨迹，验证动作支持集合和旧概率，不混入历史、评估或合成轨迹。M1 / M2 始终输出零；停止、过流和通信保护独立于策略。

## 文件与验证边界

- 实机实验：`spa_control/runs/paper_two_motor/<时间_标识>/`，含 `manifest.json`、`events.jsonl`、头部 JPEG；有有效监督区间时保存 `supervised.pt`。
- 预测模型与策略检查点：`spa_control/runs/paper_two_motor/latest.pt`，配置匹配后才恢复使用。
- 被动快照记录：`spa_control/runs/two_motor/`，不驱动电机，与实验采集分开保存。
- “离线合成检查”只检查计算接口，不运行电机，不可当作实机训练或论文实验结果。

本次实现通过软件及模拟接口验证，没有在此次开发中自主运行真实运动或完成真实模型训练，不能宣称控制收益已验证。当前仍按主机接收时钟对齐；曝光到接收、命令到实际施加的延迟尚未标定。动作的 ACK 与新鲜目标回显有记录，但不是硬件应用时刻证明。日志标记 `timing_calibrated=false`、`publication_ready=false`。真实效果、跟踪可靠性和时序精度须通过后续实验评价；当前范围仅为 **two-section SPA pilot study**。

## 依赖与测试

基础依赖和机器学习依赖分别在 `requirements.txt`、`requirements_ml.txt`。模型需本地缓存的官方 MobileNetV3-Small 权重，打开网页不会自动下载。迁移电脑时先安装：

```powershell
& .\spa_control\.venv\Scripts\python.exe -m pip install -r .\spa_control\requirements_camera.txt
& .\spa_control\.venv\Scripts\python.exe -m pip install -r .\spa_control\requirements_ml.txt
& .\spa_control\.venv\Scripts\python.exe -c "from torchvision.models import mobilenet_v3_small,MobileNet_V3_Small_Weights; mobilenet_v3_small(weights=MobileNet_V3_Small_Weights.DEFAULT)"
& .\spa_control\.venv\Scripts\python.exe -m unittest discover -s spa_control/tests
```
